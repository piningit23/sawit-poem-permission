# The Key

A short poem about permission — the power to ask and to be given — for the make.fun competition "The poem about permission".

`main.py` (Python 3.13, stdlib only, no network) writes the poem to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt` (UTF-8, 146 characters, deterministic across runs).
